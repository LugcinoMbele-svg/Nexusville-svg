# Skyline Weather Dashboard

A responsive, dependency-free weather dashboard built with HTML, CSS and vanilla JavaScript. It uses the free [Open-Meteo](https://open-meteo.com/) forecast API and its geocoding API, so no API key or server is required.

## Features

- Search by city or place
- Current temperature, apparent temperature, humidity, wind, precipitation and UV index
- Five-day forecast with weather symbols
- Responsive layout for mobile and desktop
- Loading, error and refresh states
- Uses the visitor's selected location timezone

## Run locally

Open `index.html` directly in a browser, or serve the repository with any static web server. GitHub Pages is supported.
